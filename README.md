# mrt-plus-site

Публічний сайт мережі діагностичних центрів «МРТ ПЛЮС».
Поточний стан: збірка **0.87**. Головна перебрана на три блоки: вітання
з вибором міста, «Чому МРТ ПЛЮС», «Навіщо обстежуватись зараз» із панеллю
запису. Секції центрів, послуг, відео, голосів і питань зняті з головної –
їхнє місце на сторінках міст і в розділі «Пацієнтам». Сторінка стилів поки
описує старий набір компонентів: розбіжність є, її треба закрити.

## Як подивитися

Відкрити `styleguide.html` подвійним кліком. Збірка не потрібна: це звичайний
HTML і CSS без залежностей. Шрифти лежать у репозиторії, інтернет не потрібен.

## Перед заливанням

```
python3 perevirka.py
```

Валідатор перевіряє довге тире, невизначені CSS-змінні, биті локальні
посилання, парність тегів, цілісність JSON, а також:

- **класи** – кожен клас у розмітці описаний у CSS;
- **ціни** – будь-яка сума в гривнях несе клас `price`;
- **інлайнові стилі** – заборонені повністю: саме через них головна
  починала розходитися зі сторінкою стилів.

Ненульовий код виходу означає: не заливати.

Окремо, вручну, є звірка обчислених стилів між `index.html` і
`styleguide.html` – скрипт відкриває обидві сторінки в headless-браузері
і порівнює шрифт, кегль, вагу, колір, фон, радіус і падінги 23 компонентів
в однакових контекстах. Прогонити варто після кожної зміни компонента.

## Стек

Статичний HTML і CSS без збірки. Питання стеку для внутрішніх сторінок
лишається відкритим (Next.js або генератор на Python, як у «Медикал Плюс»);
`tokens.css` переноситься в Tailwind через `@theme` без зміни значень, а
розмітка компонентів однаково лягає і в React-компоненти, і в шаблони
генератора. Вибір стеку не блокує роботу над виглядом.

## Правила, які тримають систему

- **Інлайнових стилів немає.** Оформлення живе в класах, інакше сторінка
  стилів перестає бути правдою.
- **Один надзаголовок** – `rubric`. Великий двоколірний `h2` отримують лише
  змістові секції.
- **Дві однакові площини поспіль не ставляться.** Порядок на головній:
  темна, блакитна, пісочна із золотою панеллю всередині.
- **Три ваги шрифту**: Text 400/500/600 і Display 600. Вага 700 не
  використовується.
- **Набір на темному** йде вагою 500: світле на темному оптично худне.
- **Оптичне вирівнювання лівого краю** перевіряється по краю фарби, а не
  по боксу елемента.

## Деплой

Cloudflare **Workers** зі статичними файлами – так само, як решта проєктів
акаунта. Не Pages: Pages у режимі підтримки, розвиток іде у Workers, і сайту
згодом знадобиться жива логіка (форма зворотного дзвінка, вільні слоти з API),
яка на Workers живе в цьому ж проєкті.

Створення: Workers & Pages → Create → Workers → Import a repository →
`mrt-plus-site`.

| Поле | Значення |
|---|---|
| Build command | порожньо |
| Deploy command | `npx wrangler deploy` |
| Branch | `main` |

Решту читає `wrangler.jsonc`: ім'я воркера, каталог статичних файлів (корінь
репозиторію), сторінка 404. `.assetsignore` тримає поза мережею службові файли –
`README.md`, `perevirka.py`, `docs/`, `data/`, конфіг воркера.

`_headers` віддає `X-Robots-Tag: noindex`, `robots.txt` закриває сайт від
пошуковиків. Обидва знімаються в день запуску, не раніше.

## Номер збірки

Кожна збірка отримує номер, видимий у трьох місцях: у першому екрані сторінки
стилів, у підвалі і в цьому файлі. Номер підвищується при кожній передачі
архіву – по ньому звіряється, що на Pages виїхала саме нова версія.

## Правила, які діють у цьому репозиторії

- Тільки коротке тире (–), ніколи довге.
- Повні назви послуг, без скорочень.
- Адреси сторінок – латиницею, одна схема транслітерації:
  `kyiv`, `zhytomyr`, `rivne`, `lutsk`, `kovel`, `sheptytskyi`.
- Невідомий факт не вигадується: у даних стоїть `null` і рядок у
  `potrebuye_perevirky`.
- Кольори і розміри в розмітці не пишуться – тільки змінні з `tokens.css`.
